# AlgorithmsTimeTest

Приложение на C# (WinForms) для эмпирического анализа временной сложности алгоритмов. Позволяет запускать алгоритмы на файловых данных и на генерируемых входах, измерять время, сохранять результаты в SQLite, строить графики и аппроксимировать `T(n) = C · f(n)` методом наименьших квадратов.

## Возможности

- **Одиночный запуск** алгоритма на данных из файла.
- **Серия по файлу** — прогон алгоритма на префиксах файла длины `n` с построением графика `T(n)`.
- **Серия замеров** на генерируемых данных (фиксированный seed для воспроизводимости).
- **Аппроксимация** `T(n) = C · f(n)` и расчёт MSE.
- **Автоподбор `N_max`** — эмпирический поиск максимального `n`, при котором прогон укладывается в 5 секунд.
- **Пакетный запуск** всех алгоритмов реестра с экспортом общего отчёта.
- **Сравнение трёх алгоритмов возведения в степень** на логарифмической шкале.
- **Heatmap умножения матриц** (зависимость времени от `n` и `m`) через ScottPlot.
- **Хранение в SQLite** с кэшем: повторный запуск подтягивает ранее сохранённые замеры.
- **Экспорт отчёта** в CSV: сводка аппроксимаций + таблица замеров.

## Алгоритмы

### Часть I. Векторы

| Алгоритм | Сложность |
|---|---|
| Постоянная функция `f(v)=1` | O(1) |
| Сумма элементов | O(n) |
| Произведение элементов | O(n) |
| Полином (наивно) | O(n²) |
| Полином (Горнер) | O(n) |
| Сортировка пузырьком | O(n²) |
| Быстрая сортировка | O(n log n) |
| Timsort (стандартная) | O(n log n) |

### Часть II. Матрицы

| Алгоритм | Сложность |
|---|---|
| Умножение матриц (классическое) | O(n³) |

### Часть III. Индивидуальные алгоритмы

| Алгоритм | Сложность |
|---|---|
| Сортировка слиянием | O(n log n) |
| Алгоритм Штрассена | O(n^2.807) |
| Алгоритм Дейкстры (матрица смежности) | O(n²) |

### Часть IV. Возведение в степень (подсчёт шагов)

| Алгоритм | Сложность |
|---|---|
| Наивный | O(n) |
| Рекурсивный | O(n) |
| Быстрый (бинарный) | O(log n) |

## Принципы работы

### Генерация входных данных

Данные для серии замеров генерируются автоматически с **фиксированным seed** (`new Random(42)`). Это обеспечивает воспроизводимость: для одного и того же `n` входной вектор всегда одинаков, поэтому шум от вариативности данных не смешивается с зависимостью от `n`.

### Замеры

Для каждого `n` алгоритм прогоняется **5 раз** (настраивается), берётся **медиана** — она устойчива к выбросам операционной системы.

### Аппроксимация

Метод наименьших квадратов для одного коэффициента:

    C = Σ(T_i · f(n_i)) / Σ(f(n_i)²)
    MSE = (1/k) · Σ(T_i − C · f(n_i))²

Теоретическая модель `f(n)` задаётся для каждого алгоритма (`n`, `n log n`, `n²`, `n³`, `n^2.807`, `log n`).

### Автоподбор `N_max`

Начиная с `n = 10`, размер увеличивается в **1.5 раза** до тех пор, пока один прогон не превысит **5 секунд**. Последнее успешное `n` становится `N_max`. Не применяется для Pow-алгоритмов (там измеряются шаги, а не время).

### Хранение

Все замеры и аппроксимации сохраняются в **SQLite** (`experiment.db`). При повторном запуске алгоритма, для которого уже есть замеры, предлагается использовать кэш.

## Технологии

- C# / .NET Framework 4.7.2, WinForms
- `System.Windows.Forms.DataVisualization.Charting` — графики `T(n)`
- `ScottPlot.WinForms` — heatmap умножения матриц
- `System.Data.SQLite` — хранение результатов

## Сборка и запуск

1. Открыть решение `AlgorithmsTimeTest.slnx` в Visual Studio.
2. Восстановить NuGet-пакеты (`ScottPlot.WinForms`, `System.Data.SQLite`).
3. Собрать (**Build → Rebuild Solution**).
4. Запустить (**F5**).

При первом запуске в папке с `.exe` создаётся БД `experiment.db`.

## Формат файла входных данных

Текстовый файл с целыми числами, разделёнными пробелами, табами, запятыми, точками с запятой или переводами строк:

    742 105 933 268 511 84 617 390 458 721
    15 962 553 204 871 336 689 490 127 808

## Экспорт отчёта

CSV-файл содержит два раздела:

    === СВОДКА ПО ВСЕМ АЛГОРИТМАМ ===
    Algorithm;Display;Model;C;MSE;Timestamp

    === ЗАМЕРЫ (медиана по n) ===
    Algorithm;Display;N;MedianMs

Разделитель — `;`. Для корректного открытия в Excel: **Данные → Из текста** → указать `;`.
